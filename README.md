# 🌿 Ritual — Supplement Wellness Landing Page 💊

> A modern, editorial-inspired wellness landing page focused on transparency, science, and everyday health.

## ✨ Overview

Ritual is a premium supplement landing page designed around **clarity, transparency, and trust**.  
The experience combines editorial visual design with interactive product storytelling and purposeful motion.

---

## 📝 Description

The website presents Ritual's supplement experience through a clean, bold, and modern interface with strong typography and expressive visuals.  
It guides users through product discovery, ingredients, science, testimonials, and FAQs using a structured storytelling flow.  
Interactive elements such as the draggable capsule, smooth navigation, hover states, and animated sections make the experience engaging while keeping the UI minimal.

## 🧩 Sections

### 🏠 Hero
Introduces Ritual with a bold headline, product visual, and clear call-to-action.  
Creates a strong first impression with a clean and engaging layout.

### 💡 About Ritual
Explains Ritual's approach to simple, transparent, and science-backed wellness.  
Introduces the idea behind the brand and its products.

### 👥 Who It's For
Highlights different life stages and wellness needs supported by Ritual.  
Helps users quickly understand which products may fit their lifestyle.

### 💊 How It Works
Explains the capsule experience through an interactive visual.  
The draggable capsule adds an engaging way to explore the concept.

### 🧪 Ingredients
Highlights the ingredients used in Ritual products with a focus on transparency.  
Presents product information in a clear and easy-to-understand format.

### 💬 Testimonials
Showcases customer experiences and feedback about Ritual products.  
Builds trust through simple and authentic member stories.

### 🎯 Get Started
Encourages users to begin their daily Ritual with a focused CTA.  
Creates a clear next step for visitors interested in the products.

### ❓ FAQ
Answers common questions about Ritual and its products.  
Uses an interactive accordion to keep information organized and accessible.

### 🌿 Footer
Provides important navigation, newsletter signup, and supporting links.  
Finishes the experience with a clean and structured footer.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/01Maya/Ritual.git
cd Ritual
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Open in your browser

```text
http://localhost:3000
```

## 🏗️ Production Build

Build the project for production:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
---

## 🚀 Deployment

The project is deployed using **Vercel**.

To deploy your own version:

1. Fork or clone the repository.
2. Install dependencies with `npm install`.
3. Connect the repository to Vercel.
4. Set the framework to **Next.js**.
5. Use `npm run build` as the build command.
6. Deploy.
